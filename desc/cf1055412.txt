What is Each Pack?

Main Pack: This pack contains all the Main Features

Optional Packs: These packs are Additional Packs that work along with the USTP Main Pack to add Optional Features that can be Customized to Enhance your Minecraft Experience!

Optional Features include Dark or Transparent UI, Clear Water, Clear/Clean/ Borderless Glass, RGB Portal, RGB XP Bar, Shorter Swords, Lower or Sides, Ore Borders, Glass Doors and Trapdoors, Invisible Item Frames, Clear Particles and Redstone Power Indicator.

(UTTP) Touch Pack: The Additional Version of USTP designed for Touch Players, features the Touch Circle, Invisible Touch Buttons, Clean Hotbar, F1 Button, Quick Crafting, Trading and Quick Chat Tweaks.
