SHOWCASE

FUNCTIONALITY

To use the addon...

It's quite simple! You can activate the Vein Miner by sneaking (or optionally configure it to be always active while mining), and whenever you mine an ore, it will break all connected ores of the same type in an instant!

FEATURES

- Fast Mining - Break down minerals faster and more efficiently

- Custom Activation - Choose between sneaking or standing to trigger the effect

- Tool Protection - Prevents tools from breaking automatically if durability is too low

- Auto-Pickup - Enabled by default or configurable to automatically pick up ores into your inventory

- Mined Blocks Counter - Shows exactly how many ores were mined in the action bar

- Intuitive interface - Easy-to-use form menus for configuration

- Multi-purpose - Great for mining large veins quickly

- Server mode - Permission system for administrators in multiplayer

- Lag-free - Optimized code (40% improved) to not affect game performance

HOW TO GET THE ITEMS

The main feature works automatically without items! However, to change settings, you need the Configs Menu:

Configs Menu Recipe:

Materials needed:

1x Cobblestone

1x White Dye

Or use commands:

/give @s dl_vm:configs_menu

You can also create them from the inventory in creative mode! (Found in the "Equipment" category)

PERMISSIONS SYSTEM

The first player to join the world automatically becomes the Original Operator.

- Operators can access all settings and configure the addon.

- Original Operator can grant/revoke operator permissions to other players.

- Server Mode can be enabled/disabled to require operator permissions.

Recognized operator tags: operator, op, admin, administrator, moderator

COMPATIBILITY

This addon is completely compatible with other addons and does NOT use experimental features!

- Compatible with achievements.

- No experimental features required.

- Works in survival and creative modes.

- Multiplayer compatible (server mode included).

- It may be compatible with addons that add custom pickaxes and custom ores.

INSTALLATION PROCESS & SUPPORT

Correct installation process:

- Download both files, the behavior pack [BP] and the resource pack [RP] (If you only download one of the two .mcpack files, the add-on may not work properly).

- Import both files into Minecraft Bedrock. One at a time.

- Activate the add-on in an old or new world. When you activate one of the two, the other will automatically activate. For example: if you activate [RP] -> [BP] will automatically activate.

- Enjoy :)
