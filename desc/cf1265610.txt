This add-on works for most versions, from since I was testing it works as far back as 1.21.50 (minus any components I use in new versions, which should only limit behavior and not make it completely unfunctional)

If new entities do not work on older versions this is something I cannot fix. A lot of the new entities we are creating depend on functionalities only found in newer minecraft versions.

You only need to download the latest version which includes features and mobs from all previous version. Downloading a newer version after downloading and older one and importing it will just update the pre-existing content with the new content. I did this for your ease :)

The male deathmoths (smaller ones) can be tamed with sticks, you can change this in the deathmoth.json file where it says "minecraft:stick" change it to your item of choice.
Yes, deathmoths and dunks were purposely made to spawn in with a name tag, this is because there is a minecraft bug where custom tamed entities will say "Unknown was killed by player" if the tamed entity were to die and this was my only fix.
