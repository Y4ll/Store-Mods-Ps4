No Beta APIs Required

Just (Sneak) while using the right tool no more chasing ore veins block by block or chopping every log manually.

Features

- Vein Mining, Sneak + break any ore to instantly mine all connected blocks of the same type

- Tree Capitator, Sneak + break any log to fell the entire log in the tree at once

- Proper Tool Tier Checks, Respects vanilla tool requirements (e.g. Iron Pickaxe+ needed for Gold Ore)

- Fortune & Silk Touch Support, Enchantments apply correctly to every block broken

- Unbreaking Support, Durability is consumed per block, with Unbreaking taken into account

- Creative Mode Compatible, Works in Creative Mode with the correct tool; no durability loss

- Up to 1,280 blocks.

Supported Wood Types

Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Pale Oak. including their stripped variants and wood blocks.

How to Use

1. Equip the correct tool for the block type (works in both Survival and Creative!)

2. Hold Shift (Sneak)

3. Break any supported ore or log

4. The entire vein or tree breaks at once!

Requirements

- Minecraft Bedrock Edition 26.0 or higher

- No Beta APIs required uses fully stable Script API (@minecraft/server 2.7.0)
