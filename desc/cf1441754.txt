MY DISCORD

This add-on provides more swords.
You can craft each sword through the crafting table.
The harder the materials are to obtain, the stronger the sword will be.
Some swords can only be obtained by upgrading swords you have already crafted.

Sword+

- dragon fang

- black dragon fang

- black diablo sword

- pirate blade

- crimson sword

- aladin blade

- gold aladin blade

- bone blade

- elite diamond sword

- netherite diamond sword

- royal katana

- blood royal katana

This add-on is achievements friendly.
This add-on does not include player.json.
This add-on does not require experimental features.
If the add-on does not work, please report it on Discord.
If you want to request an add-on, please make a request on Discord.
If you want to collaborate or work together, please contact me on Discord.
