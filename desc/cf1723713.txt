PSX Flashback Shader

This Shader Developed by @PnTMC

Inspired by Twixxel's SILAS and ckosmic's PlayStation 1 Graphics

Reminder : This is RenderDragon shaders, so you need to use the correct tools to use this shader ( e.g. MaterialBinLoader, BetterRenderDragon, Minecraft Patch, or any shaderloader )

Currently, only version 26.40 and earlier are supported; 26.50 will be available soon.

When you use this shader, the Minecraft Bedrock version you usually play turns into a PSX-style game.

This shader is suitable for add-ons with horror or medieval themes.
