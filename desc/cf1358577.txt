What is Just Rubber Duck'es?

Just Rubber duck'es is addon created for the Collecting and Customizing Rubber Ducks.

========================================
VIBRANT UPDATE

===================================================================================================

DUCK DISPLAYS

The Ducks themselves are just crafted with a single armor stand.

rubber ducke recipe

Duck'e Set

===================================================================================================

BAGS

Like Just Cosmetics(gif) this addon uses a bag drop for obtaining the special Variants and skins.
There is a 5% chance of the

Duck'e Bag

dropping from any and all mobs including those from other addons.
When using the bag it will drop a rubber duck'e

Rubber Duck'e

(picture of ice cream variant)

or the

Duck'e Cosmetic Bag
Which can drop a dyeable skin

(picture of no eye variant)

=================================================

Combine individual ducks to create sets

(Dessert set)

=================================================

All skins are trimmable

(No eye/no bill skin with bolt trim using resin material)

Currently only custom Bolt and Flow Trim Available

=================================================

Fully Equippable

The Ducks are fully Equippable with armor(Both vanilla and other add-ons).
Skins take up the feet slot.

======================================

Dyeable water and lava

craftable in 3 sizes

7x7

16x16

21x21

Craft with buckets of the appropriate liquid

Dye with a cauldron

Equip duck with the item

Layering using snow layers

Layering using half slabs
(both images are using the same dyed water)

======================================

CREATE SCENES

The ducke set has some dynamic poses that change the orientations, mixed with dressing them up, you can get creative

=====================================================

SEASONALS

As of right now, there are 4 holidays

-Easter
-Summer (July 4th)
-Halloween
-Festive (Christmas)

THESE EVENTS ARE REAL TIME AND WILL START DROPPING AUTOMATICALLY

-Seasonal ducks will start dropping a week before their corresponding holiday. They run through the holiday and a week after.
Example =Easter(13-27)

There is also a holiday duck set that requires the skin from each of the holidays
