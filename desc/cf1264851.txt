Configurations (_global_variables.json)

- $use_jei_layout = true is default, change it to false to disable the Jei layout and use default Minecraft layout

- $transparent_jei = true is default, change it to false to use the non transparent variant

- $item_hover_text_position = bottom_right (default), bottom_left, top_left, top_right
