DESCRIPTION

Slim Player Model
Set the Player model to Slim version [will effect everyone else]

Armor Outline Colors
Set Outline Colors for All Armors [there's limitation that makes the attachable items can't be set its own RGB value]

Black, Gray, White, Red, Brown, Orange, Yellow, Green, Dark Green, Lime, Cyan, Blue, Dark Blue, Violet, Purple, Pink, Neon

Rainbow Color

Rainbow Color RGB Speed value

Passing Through
