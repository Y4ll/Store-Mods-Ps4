Inspired by apace100, creator of the Java Origins mod, but this version is built from scratch for Bedrock. Each origin has unique strengths and weaknesses, keeping the experience balanced. Remember: not all advantages are about combat - consider every aspect when choosing.

Origin abilities grow stronger as you gain XP levels

Each origin has active abilities triggered using the item

Your Mana is shown in the bottom-right as a bar and counter

You get 3 free origin resets. After that, craft an Origin Eraser to reset again(Admins can change this)

If you lose this item, craft one using a dirt and 4 sticks

As admins, to create or edit custom origins, give yourself the z-operator tag

*Created by ZAZACKE and Halfpotato
Suggest origin ideas or report bugs at YouTube/@zazack6260 or Discord/zazacke

Origin Selection menu:

Admin Settings

This form lets admins to Allow or disallow specific origins , disable or change origin reset count,

do :

/zop add @sor /tag @s add z-operator

to access this menu

Custom Origin Creator (Ingame)

This menu Allows admins to create custom origins and abilities, with diffrent stats and abilities with no limits, Try not go beyond limits as it may cause crashes, Only z-operators can access this settings

Additional Modules

You can add optional modules to the main origins list by stacking specific packs as modules , make sure that the main module stays on top
