Configure

If you are an operator, you can type /vmtc:config in chat to open the configuration menu.

Here is what the config menu looks like:

Iteration Limit:

Change how many blocks can be broken per VM/TC activation.

By default it's 150. Increase if you have a good device, decrease if it's too laggy!

Toggle Tools:

Toggle specific tools on/off. Or you can toggle all of em off!

Tool Whitelist:

If you've disabled a tool, you can add the tool you're holding to the whitelist

which bypasses the toggle tools. Good if you only want

specific players using VM/TC.

Extra Toggles:

Durability Per Block - Toggle whether durability is taken per block broken, or only once.

Join Guide - Toggle whether it shows the one-time guide when a player first joins.

Settings Msg - Toggle whther it shows the "Updated Settings" message in chat.

Crouch to Use - Toggle whether you must crouch to use Vein-Miner, Tree-Capitator, etc.
