If you like satisfying and instant things, then Vein Miner will fulfill your request. This add-on allows you to mine ores instantly.

For example: if you are mining 7 diamond ores, you only need to break 1 diamond ore, and the other 6 diamond ores will break at the same time.

Note: to apply this feature, you must mine using an official Minecraft pickaxe. If you mine with your bare hands, this will not work.

This add-on does not include player.json.
This add-on does not require experimental features.
If the add-on does not work, please report it on Discord.
