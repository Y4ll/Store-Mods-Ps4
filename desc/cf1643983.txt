As for the elevator preset, you need to switch a config card's mode to elevator mode.
Then fill in the data following the instructions shown on the config card.

1. Place a barrel below the elevator button.

2. Put the configured config card inside this barrel.

3. Link the barrel to the elevator button.

If the indicator screen turns green, the button is functional.
Repeat the steps above to configure the remaining elevator buttons.

Important: You must link every two corresponding floors with each other.

When you finish setup, press a fullyconfigured elevator button. If the nearby elevator door opens, your elevator system works properly and you are ready to use it.

Tip: You can copy a config card by using it while sneaking.

About Elevator Preset (NewVersion Feature)

The new version adds elevator mode to config cards for elevator buttons.

- Fill in required data on your config card

- Put a barrel under the elevator button

- Insert the filledout config card into the barrel

- Link the barrel to the elevator button

A green indicator means it is ready. Repeat for other buttons.
