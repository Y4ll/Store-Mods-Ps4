Ever wanted to travel through dimensions like Rick and Morty? Now you can!

The Portal Gun Add-On brings fully functional portal guns to Minecraft Bedrock, allowing you to create portals, travel across your world, and even explore custom dimensions.

Create your portal gun, choose your destination, and step through the portal. Whether you're building massive transportation systems, escaping dangerous situations, or simply experimenting with portals, the possibilities are endless.

Features:

- Create and link multiple portals

- Travel between different dimensions

- Support for most custom dimensions

- Save your favorite locations

- Choose from multiple Portal Gun skins

- Configure your Portal Gun's behavior

- Portals adapt to different sizes and orientations

- Linked portals can protect you from fall damage

- Create Portal Fluid and refill your gun whenever necessary

- Track your Portal Gun if it's dropped or lost after death

- Rick and Morty-inspired accessories

After creating your Travel Solution, place it on the ground and interact with an empty tube to fill it with Portal Fluid.

Next, place the Portal Fluid in your offhand and interact with the Portal Gun Base to assemble your Portal Gun. You can also use empty tubes instead of charged ones.

Once assembled, simply interact to shoot a portal, or Shift + Interact to open the Portal Gun's menu. Each Portal Gun has its own unique interface!

Setting Coordinates

The Portal Gun allows you to set specific coordinates as a destination for your portals.

When entering a coordinate, use the following format:

x y z dimension_id

For example:

100 64 200 overworld

The dimension ID specifies which dimension the portal should be connected to.

For vanilla Minecraft dimensions, the minecraft: namespace is optional.

Both of these formats work:

100 64 -250 overworld

100 64 -250 minecraft:overworld

For custom dimensions, you must use the exact dimension ID, including its namespace.

For example:

100 70 200 myaddon:custom_dimension

Make sure the ID matches the dimension's registered ID exactly. Otherwise, the Portal Gun will not be able to find the destination dimension.

Finding a Custom Dimension ID

If you don't know the ID of a custom dimension, you can easily find it using the Portal Gun's terminal.

First, travel to the custom dimension by any other means. Then, open the Portal Gun's Terminal, which can be found under Settings.

Run the following command:

coords

The terminal will display your current coordinates along with the exact ID of the dimension you're in. You can then use this ID when setting a destination coordinate.

Installation

First, download the latest version of the Portal Gun Add-On that is compatible with your version of Minecraft Bedrock. Once downloaded, you should have the addon .mcaddon file.

The next step depends on your device:

- Windows: Simply open the .mcaddon file with Minecraft. The addon will be imported automatically.

- Android: Open the downloaded .mcaddon file using a file manager and select Minecraft when prompted.

- iOS: Open the .mcaddon file using the File
