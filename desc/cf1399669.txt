This pack is a block add-on focused on construction.

It contains everything you need for modern architecture, recreating Japanese streetscapes, and general building!

Pack introduction

INAKA

This pack allows you to add blocks suitable for modern architecture and Japanese cityscapes.

Number of blocks: 57

Each block features over 100 variations in total.
Block introductions and usage guides are available on YouTube.
