Mouse Wheel Tweaks is a texture pack that adds functions to the mouse scroll wheel for inventory management. You can move items by scrolling the mouse wheel, just like the mods in Minecraft Java.

How To Use:

- Hover over a slot to start moving items with the mouse scroll wheel.

- It also works on output slots like crafting output slot or furnace output slot, but only Move One mode that works.

- There are two modes for moving items: Move One and Move All. You can switch between them with the TAB key.

- You can also move items by dragging them while scrolling the mouse wheel.

- There are subpacks to select the default mode when opening the screen.

reference: https://www.curseforge.com/minecraft/mc-mods/mouse-tweaks

NOTICES:

- This pack does not support bundle items because it conflicts with mouse scrolling to select items within the bundle.
