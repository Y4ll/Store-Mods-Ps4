What is the Super Glue Addon?

Super Glue is a Minecraft Bedrock addon that introduces a fully custom physics engine inspired by mods such as Create Mod, Clockwork, Valkyrien Skies, and Create Aeronautics.

It allows you to weld ordinary Minecraft blocks into fully dynamic physics objects that can move, rotate, float, fly, and interact with the world.

Build creations such as:

- Cars and trucks

- Boats and submarines

- Airships and airplanes

- Helicopters

- Windmills and turbines

- Moving doors and elevators

- Walking machines

- Entire movable houses

If you can build it, you can bring it to life!

Tools and How to Weld Objects

- Super Glue (Stick): Best for selecting custom shapes block by block. Break blocks to select them. Use the item while looking at the sky or air to weld the selected blocks into one physics object.

- Box Glue: Best for selecting large areas quickly. Use the item on a block to set Point 1, and another block for Point 2. Use it while looking at the sky to weld. Crouch and use the item to clear your selection.

- Drag Tool: Allows you to pick up and move welded creations. Use while aiming at a physics object to grab it, and use it again to release. (Newly Improved: Dragging now supports more advanced movements and object manipulation!)

- UnGlue Glue: Converts a physics object back into normal Minecraft blocks. Use while aiming at a welded creation to snap it back to the grid.

- Ropes and Springs: Creates dynamic physical connections between two points. Use the item on the first point, then on the second point to connect. The Rope Tool creates standard cables with tension, while the Spring Tool creates bouncy, elastic connections.

- Signal Remote: Pairs with Signal Receivers to wirelessly toggle your electrical systems and Current from a distance.

- Sonic Handheld Gun: Throws an Echo Wave Attack. The output power determines how far the attack is thrown. The higher the power, the more EXP it requires to fire.
