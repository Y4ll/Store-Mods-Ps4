CUMULUS is a PvP-oriented resource pack for Minecraft Bedrock Edition that provides a wide range of optional visual, HUD, and gameplay-enhancing features. All features are client-side visual modifications and can be individually enabled or disabled through the pack's settings interface.

Included Features (v1.7)

- Hitbox Display

- Footprints

- Sprint Tag

- Kill Effects (excluding Hive)

- Custom Capes

- Custom Cubemaps

- 3D Projectiles

- Movable Armor HUD

- Pinch Alert (customizable health threshold)

- Reach Visibility

- Auto Swing Animation

- Waypoints (with customizable duration)

- Hurt Particles

- Using Particles

- Custom Hurt Color (RGBA)

- Rings

- Hand Animations (Vanilla / Java / RTX)

- Custom Hand Positions

Feature Configuration

All features can be enabled, disabled, or customized through the included settings interface.
