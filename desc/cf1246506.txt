Notes

- One other little thing I forgot to mention, Newb X Dawn is in name only and because it is based on an RTX package, you don't need to have an RTX to use this variant, you can run it on any device.

- You must place this shader above the other active packs to avoid errors.

- Need Minecraft v26.50 and MBLoader.

- Need Minecraft Hynis in iOS.

- You need Wyvern for Windows, in case it does not work, use the method of replacing material.bin files with Maject.

- I recommend that you the old version of this shader if you have it installed to avoid errors.

- This shader is only compatible with Android,Windows and iOS
