Bring a modern, clean, and customizable user interface to Minecraft. HorizonUI focuses on visual clarity, animated backgrounds, and layout refinement to deliver a fresh and immersive UI experience

Features:

HorizonUI: BE has several features that make it easier for you to play survival mode :D

- Quick Loot Items

- Quick Move Items

- Quick Drop Items

- Inventory Slot Counter

- Item Counter & Stack Counter

- Brewing Guides

- Smithing Guides

NOTE:

HorizonUI: BE is still in development and is currently in EXPERIMENTAL status, which means there are still some bugs and some features that aren't fully functional yet.
