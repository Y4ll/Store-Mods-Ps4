War of Shinobi

About this Add-On!

Shinobi War is an Add-On inspired by an Anime/Manga called Naruto, by Masashi Kisimoto with Anime produced by Pierrot Studio.

The point is, in this Add-On you can choose the characters in the Anime/Manga, according to what we want, but this Add-On is still BETA, and there are definitely bugs too, im sorry if there are annoying bugs.

Menu Select

If you want to Select Characters, use the Menu Select items, and then will show this UI, there is 3 button.

- Select Characters = Literally just for select the Characters that you want

- Reset Characters = Click this button if you want change to another Characters

- Help = Guide for you

Selection Category

Characters category, select characters according to category.
