Features

- XP storage system using vaults

- Punch a vault to store XP

- Shift-punch a vault to withdraw XP

XP Amounts:

- Small = 910 xp = 25 levels

- Medium = 2805 xp = 40 levels

- Large = 13515 xp = 70 levels

Usage Tutorial

- Craft a vault (recipes available in the green book).

- Place the vault in the world.

- Punch it to store XP.

- Shift-punch it to retrieve stored XP.
