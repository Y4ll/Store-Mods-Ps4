Nostalgic Textures

Nostalgic Textures brings back the classic Minecraft feeling while keeping the modern Bedrock experience.

This pack combines a large collection of nostalgic textures, visual changes and classic-style improvements into one complete resource pack.

Features

Classic & nostalgic block textures

Classic-style weapons and tools

Classic-style armor textures

Updated item textures

Nostalgic environment textures

Classic-style sun, moon and sky elements

Weather and environmental textures

Particle textures

Modified UI elements

Nostalgic menu panorama

Biome visual resources

Controller/UI elements

2,800+ resource files

Designed to recreate the feeling of older Minecraft versions

The Old Minecraft Feeling

Nostalgic Textures is made for players who miss the old Minecraft aesthetic but still want to play on modern Bedrock versions.

It doesn't completely change Minecraft's gameplay. Instead, it focuses on bringing back the classic visual style and nostalgia.

Old textures. Classic feeling. Modern Minecraft.
