Console Aspects bridges the gap between Bedrock and Legacy Console Edition. It changes color grading, distance fog, explosion particles, zombie pigmen, menu sounds, and many other things. Now, you can enjoy the classic style of Legacy in modern Minecraft Bedrock.

Check out Java Aspects for the Java Edition style on Bedrock.

Creator: AgentMindStorm, Bluesky Account, YouTube Channel (Click here for more credits.)

Pack Options

Explore the different ways to use Console Aspects.

Default Textures

Matches the final update for PS4 Edition. Old mobs and potions, with updated block textures.

Classic Textures

The original look of Minecraft. You must apply the Minecraft Classic Texture Pack from the Marketplace below Console Aspects for the subpack to work correctly.

Updated Textures

The same Legacy style without outdated mob textures, sounds, or item names.

Compatibility Mode

Allows another resource pack to overwrite textures while keeping Legacy sounds, animations, and language changes intact. Apply the other pack above Console Aspects.

(Note: Halo Mash-up Pack not included!)
