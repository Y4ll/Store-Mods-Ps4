Installation

Disclaimer: Minecraft Bedrock does not officially support loading custom shaders. The following are unofficial methods for loading shaders.

Android

1. Install MB Loader APK.
2. Import the resource pack to Minecraft and activate it in global resources.
3. Launch Minecraft through MB Loader APK.

Windows

- Use BetterRenderDragon or MatJect to enable Material Bin Loader (shader loader).

- Import the resource pack and activate it in global resources.

If BetterRenderDragon does not support your Minecraft version, use this Matject tool (search in github) to install shaders.

Linux (x86_64 arch)

This method is for mcpelauncher-manifest.
1. Install mcpelauncher-materialbinloader-mod.
2. Import the resource pack and activate it in global resources.

*iOS

Sorry. There isn't an easy method to install shaders on iOS devices. You either require jailbreak or would have to install an untrusted IPA.
