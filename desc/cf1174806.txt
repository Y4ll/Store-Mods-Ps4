This addon allows you to have a working minimap, with shadows and a player locator, in your world without using any external tools!!!

You can use the 16x or the 32x version according to your preference but I recommend you to only use the 16x version because this addon is very performance heavy.

Please keep in mind that this addon is only in BETA right now so if you encounter any bugs, that's completely normal and please feel free to report them back to me.
