Are you looking for a FOG that change weather or condition in a game? well, this is you may look for, this pack change visual in-game start from dark vibe Minecraft into sandstorm.

Basic Information

Weather FOG Specifications

- Features/Settings:

- Set to Vibrant Visual, it's ok if you device can't run it, you can still enjoy it.

- Vibrant Visual Option: Shadow Quality: Low, Clouds: Medium, Volumetric Fog Quality: Low, Reflections: Low, Bloom: 50%

Weather FOG Visual

To change the visual at Global Resources > Active the pack > click Gear icon.
