Changing to a different Subpacks or Variant

if you're new in Minecraft, and don't know what the subpacks is. please scroll down at the bottom of this Description, and read the FAQ below you'll find "Pack Settings & Subpacks" section

Set Custom Subpacks

below subpack slider, there's a lot of customization you can set. i separate them so you can choose which variant and model you want. it only set the texture or model to the spear variant you choose, so it'll not messing around with the other variants. it's also giving you a flexibility to use a different model through every subpacks.

How to Control it?

- Make sure you've set the subpack to "CUSTOM"

- Below it, there's a dropdown button

- every spear variants have a dropdown option, with the description above it of which spear variant it'll set

- After you pick which one, you're done :)

- Even you can change this settings while playing the game

- At the very bottom there's dropdown for outline color that's appears when the spear is enchanted.
