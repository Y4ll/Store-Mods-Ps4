Useful Tips

== Pattern Creation ==

Using Pattern Create table, you can select the type of design for your pattern. To use this table:

- Place a blue pencil in the top left slot

- Place an empty pattern in any of the 6 middle slots

- The drawing will be automatically created

Patterns

Iron/Gold/Diamond Plate

Obtained by clicking on an ore-related block with any hammer.

Example: Click on an iron block with any hammer to get an iron plate.

Steel Shard

Created by smelting an iron plate in a furnace or blast furnace.

Skilled Anvil

This table allows blade creation:

- First slot: Ore plate determines blade material

- Third slot: Pattern design determines blade type

- Middle slot: Any hammer (material doesn't need to match blade)

== Rituals ==

- Place a pedestal on the ground

- Count 3 blocks in each direction and place another pedestal (2-block gap between pedestals)

- Required items:

- Center pedestal: Deepsteel Ingot

- Other pedestals: Crystals corresponding to desired steel type

Crystals (all craftable):

- Illuminatic Crystal

- Magmatic Crystal

- Endynium Crystal

Steels (obtained from rituals):

- Illuminatic Steel

- Magmatic Steel

- Endynium Steel

Note: Up to 3 different items can be obtained depending on crystal used
