Ever wished to use Minecraft's ray tracing with higher resolution vanilla-styled textures? With RTX Reactor it is now possible for anyone to use every resource pack with ray tracing, and Faithful is no exception!
Faithful RTX is a free Faithful conversion for Minecraft with RTX on Bedrock Edition, generated by RTX Reactor upon the latest version of the Faithful resource pack.

Ray tracing support for this pack was automatically added using RTX Reactor. RTX Reactor is a program that is made to quickly & effortlessly generate RTX support for any Bedrock Edition resource pack. It is still in development so minor issues and some imperfections are possible. This post will be updated with new iterations of Faithful RTX whenever a major RTX Reactor update is released, so expect the quality of Faithful RTX to improve as RTX Reactor evolves, which is going to serve as both a demonstration and showcase of RTX Reactor's capabilities, and a fantastic free 32x resource pack for Bedrock players to use with ray tracing. Hope everyone enjoys!

Credits Information: Faithful 32x RTX is made upon the original Faithful 32x resource pack, RTX functionalities were later added on top of the latest version of Faithful 32x. (Latest July Release as of now)
