Installation Process

Android

- Copy "renderer" folder from "PandaMine's VVO.mcpack"

- Put it into "assets/assets/" in your mcpe APK

- Replace All files and "renderer" folder

- Sign / Build APK -> Install

Windows

- Copy "renderer" folder from "PandaMine's VVO.mcpack"

- Put it into "C:\XboxGames\Minecraft for Windows\Content\data"

- click "Replace All"

- Activate Vibrant Visuals Optimizer + Unlocker + Mip Mapper in Global Resources
