## The Base for Your Custom Minecraft Bedrock UI

**YashGameplay's Main UI** is a custom Minecraft Bedrock interface designed to serve as the foundation for compatible anime UI packs, animated menus, and other character-themed interface add-ons.

Instead of requiring a completely different interface framework for every theme, this pack provides a consistent base that allows compatible UI add-ons to use the same core menu system.

It also features a redesigned main menu with custom navigation icons, an organized layout, and a clean visual presentation that gives Minecraft PE a more personalized appearance.

## How to Use With UI Add-Ons

Download and import **YashGameplay's Main UI**.

Download and import your preferred compatible UI add-on.

Open **Minecraft Settings Global Resources**.

Place the custom UI add-on **ABOVE YashGameplay's Main UI** in the resource pack list.

Activate both packs and enjoy your customized interface.

**Important:** This is the base UI. For compatible add-on themes, keep YashGameplay's Main UI enabled underneath the selected add-on.
