The Texture Update has been officially released for years, while some of us still prefer the old textures. However, the Minecraft Classic Texture Pack from Minecraft's official Marketplace is now delisted, which is exactly what this pack aims to fix. With this pack, you can easily enjoy the classic textures, with Vibrant Visuals support and even more things fixed!

Additional Features

Extra features compared to the original Classic Texture Pack.

Vibrant Visuals Support

- Vibrant Visuals can be enabled with this pack

- Include MERS (PBR) textures for many blocks, items and entities

- Include static colored light support for lighting blocks
