V3.1.1 Fixes & Improvements

TNT Blast Jump

TNT Armor's Blast Jump has been improved.

The jump itself no longer causes unwanted fall damage when you land.

Conduit Power

Prismarine Armor's Conduit Power has been improved so the effect no longer constantly expires and reappears, preventing the annoying visual flicker.

Smarter Potion Effect Handling

Armor abilities now work much more safely with effects the player already has.

If you already have the same effect at an equal or stronger level, Block Armor leaves your existing effect alone.

If an armor ability temporarily provides a stronger version, your previous effect can be preserved and restored when the armor effect ends, as long as its original duration has not expired.

Removing the armor also removes the effect provided specifically by the armor instead of leaving it behind.

World Settings Permissions

World Settings now correctly recognize:

- World Owners / Hosts

- Operators

- Admin-level players

Players without permission can still use the normal personal features without being able to change global armor powers.

Full V3.1 Details

Brick Armor Blast Defense

Wearing the complete Brick Armor set reduces explosion damage by 40%.

It also helps reduce the knockback caused by explosions.

Gilded Blackstone Armor Piglin Defense

Wearing the complete set reduces damage received from:

- Piglins

- Piglin Brutes

Damage from these enemies is reduced by 50%.

Nether Brick Armor Wither Defense

The complete Nether Brick Armor set automatically removes the Wither effect.

It also reduces damage received from Wither Skeletons by 30%.

Log Armor Lightweight Movement

Wearing the full Log Armor set grants Speed I.

This makes the wooden set useful as lightweight exploration equipment.

Oak Planks Armor Forest Regeneration

Wearing the complete Oak Planks set slowly regenerates your health while you remain close to forest blocks.

This includes nearby:

- Logs

- Wood

- Leaves
