Colourful Containers BE is a resource pack ported for Minecraft Bedrock Edition that replaces the default boring, grey container GUIs with vibrant themed interfaces! Every menu gets a unique texture inspired by the block or entity it's from, making your UI feel like a natural part of the game.

To use the Coloured Shulker Boxes & Wood Type Chest Boats feature, you can either:

- Use the Colourful Containers BE: Script pack!

- Rename the items in an Anvil!

This texture pack is made to be used with Colourful Containers BE: Script, as it enables the automation of renaming items such as the Chest Boats or Shulker Boxes so you can use Coloured Shulker Boxes or Wood-Type Specific Chest Boat textures seamlessly!

Or

If you want to use the Anvil method, simply remove the empty space at the end of the item name!

Frequently Asked Questions & Support:

Will you add compatibility for Pocket UI?

No, I'll be soley focused on the classic UI mode.

Tips if the pack is not working:

- Make sure you have your 'gui' settings to 'classic' (NOT 'POCKET')

- If dark mode is not working. Try restarting your game after activating the subpack!
