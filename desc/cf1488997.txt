One block. Nine lucky block types. No idea what's coming next.

v2.0.0 Bedrock Edition Free BP + RP Beta APIs Required

What's this about?

So I took the classic One Block concept and added Lucky Blocks on top of it. You start on one block at Y=150, break it, it respawns. Same old One Block survival you know. But now every few blocks a Lucky Block randomly appears instead of a normal phase block and when that happens, anything can drop.

There are 9 different lucky block types and each one has its own drop chances. Like the Green block literally never gives bad luck zero bad drops. The Black block is basically 50% bad 40% legendary, so it's pure gambling. Red is the most dangerous one with 40% bad luck. Rainbow is the best one to get highest chance for Pro Legendary drops out of any block type.

The lucky block doesn't spawn at fixed intervals either. Every single block break has a 15% chance to make the next one a lucky block. If you go 12 blocks without getting one, it forces a lucky block on the 12th. So you're never waiting too long but you also never know exactly when it's coming. That's the fun part honestly.

Install both BP and RP, enable Beta APIs and join. You'll land on the block automatically. Just start breaking.
