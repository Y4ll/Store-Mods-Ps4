This add-on brings the so-called Farlands from the older Java version to the Bedrock Edition

watch a video about the addon: https://www.tiktok.com/@j.mc2026?_r=1&amp;_t=ZG-9A4oyWefCe9

They generate from x/z 10.000/100.000/500.000/1.000.000 (Changeable using subpacks) to infinity and form 4 walls so that the playable zone is 200.000 x 200,000 - 2.000.000 x 2.000.000 blocks in size.

(Inspired by the original Far Lands from Minecraft Java Edition (Beta 1.7.3).)

(This file contains only a behavior pack)
