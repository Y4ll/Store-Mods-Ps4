Want to install blocks safely? Want to make it easier to install blocks? Try this add-on! This add-on will install blocks for you!

How to use

Place the block in the upper left corner of your inventory and sneak a peek at the installation.

You will be notified when there are less than 10

Modes

There are three modes

Default is default.

You can change the mode by holding the stick and right-clicking(long tap)

Bridge Mode

In this mode, the block is placed under you.

Vanish Mode

This mode places a block under you.
After 10 seconds, the placed block will disappear and return to your inventory

Default

This is the normal mode, where no blocks are placed underneath.
