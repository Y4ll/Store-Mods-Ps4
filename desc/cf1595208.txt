X-Ray Pro Resource Pack

Creator: UpCraftX

Mine smarter and explore underground like never before with X-Ray Pro! This resource pack is designed for Minecraft Bedrock Edition, making underground exploration faster and more efficient by making most common blocks transparent while keeping valuable resources clearly visible.

Whether you're searching for Diamonds, Ancient Debris, or other precious ores, X-Ray Pro helps you locate them quickly without unnecessary digging.

Features

- Makes most common underground blocks transparent.

- Clearly highlights valuable ores for easy visibility.

- Speeds up mining and resource gathering.

- Supports both Overworld and Nether mining.

- Includes Deepslate ore variants.

- Lightweight and optimized for smooth performance.

- Easy to install and use.

- Compatible with supported Minecraft Bedrock versions.

Installation

- Import the .mcpack file into Minecraft Bedrock Edition.

- Activate X-Ray Pro from the Resource Packs menu.

- Enable the recommended video settings.

- Enter your world and start mining with enhanced visibility.

Notes
