How To Download

Note: You Must Follow These Steps Or The Skinpack Will Not Load! Also Please Make Sure You Have The Builders And Biomes Skinpack. Also Please Make Sure You Have The 1st Animal Friends Skinpack.

Windows 11

- Download The Christmas 4D 2 (PC+iOS) Skinpack

- Rename the file from Christmas 4D 2 (PC + iOS).mcpack To Christmas 4D 2 (PC + iOS).zip

- Unzip The File

- Press Windows Key + R To Open The Run Dialog

- Paste This File Directory Into The Run Box: %AppData%\Minecraft Bedrock\premium_cache\skin_packs

- Delete Everything Inside The skin_packs Folder

- Put The Unzipped Christmas 4D 2 (PC + iOS) File Into The skin_packs Folder

- Restart Minecraft You're Good To Go!

For iOS

- Download Christmas 4D 2 (PC+iOS) Skinpack

- Rename the file from Christmas 4D 2 (PC + iOS).mcpack To Christmas 4D 2 (PC + iOS).zip

- Unzip The File

- Go to On My iPad (Or On My iPhone)/Minecraft/internal/premium_cache/skin_packs And Delete Everything Inside The skin_packs Folder

- Go To Your Downloads And Hold Down On The Unzipped File And Press Move

- Move It To On My iPad (Or On My iPhone)/Minecraft/internal/premium_cache/skin_packs And Press Move

- Restart Minecraft And You're Good To Go!

- Rename The File From Christmas 4D 2 (ANDROID).mcpack To Christmas 4D 2 (ANDROID).zip
