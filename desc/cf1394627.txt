Craftable Secret Items v1.12

For MCBE 1.20+

By Sidga420

This addon allows you to craft many hidden vanilla items and blocks from Minecraft Bedrock.

- 251 illegal items in Survival (crafting recipes)

- 368+ illegal items in Creative

Achievement Friendly!

All items in this mod already exist in the game, but they can only be obtained using commands (and not always).

With the Craftable Secret Items addon, you can craft any secret blocks and items in Survival Mode using a crafting table.

The only hidden blocks and items you won't be able to craft are those that can't be used in Survival. For example, command blocks, which can't even be placed as a block in Survival.

You can find all the crafting recipes by going in crafting table in survival mode. The camera can be purchased from a blacksmith for 10 emeralds.To summon an NPC, name any villager "NPC" using the name tag.

The addon also adds all secret blocks, items, and mobs to the creative inventory.
