Installation Guide

- Scroll down and download the Skin Pack.

- Open the downloaded file using ZArchiver or any file manager app.

- Tap Open With and choose Minecraft.

- Wait for Minecraft to import the Skin Pack.

- Go to Change Skin or Dressing Room.

- Open the imported Skin Pack.

- Select any skin and start playing.
