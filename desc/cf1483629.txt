TokenSMP - Mob Ability Tokens for Minecraft Bedrock

Turn yourself into any mob with powerful abilities!

TokenSMP adds 20+ collectible tokens with 15 on joining random give and 5 one time craftable, that grant you special mob-themed powers when used. Each token has unique effects, particles, and cooldowns - from summoning wolf packs to shooting explosive sonic booms!

Features

20+ Unique Tokens - Each mob has its own signature ability

Stunning Visuals - Custom particles and effects for every ability

Balanced Cooldowns - Fair gameplay with carefully tuned cooldown times

Rare Token System - tokens that are only 1 time craftable

First Join Bonus - New players get a random token on their first spawn

Multiplayer Ready - Works perfectly on servers/smps

Rare Token System

Some tokens are limited in quantity! Chicken, Ravager, Wither Skeleton, Ender Dragon, and Warden tokens have configurable global limits. The limit is 1, If someone crafted it first and then another player tried to craft it the player will receive a material refund and a note that this is alr maded by someone else

Commands:

/tokensmp:token config - Configure rare token limits

announce when ability made ( default = true )

announce when ability dropped showing cords of location ( default = false )

announce when ability destroyed ( default = false )

Set the limit of the token

FAQ

Q: How do I get tokens?

A: New players receive one random token on first join. More tokens can be obtained through gameplay or commands.

Q: Can I use multiple tokens at once?

A: Each token has its own cooldown, so you can use different tokens while others are on cooldown.

Q: Do tokens work in PvP?

A: Yes! Most abilities affect nearby players and mobs.

Q: Can I change certaij things about craftable tokens

A: Token availability can be configured through the admin panel.
