So yeah how do you use it? its pretty easy just install the resource pack as usual and make sure you enable Show Days Played and Show Coordinates in the game settings, check the other things section below.

Other Things

setting options that must be enabled

subpacks (press settings in resourcepack), you can change the display, tip: use subpack 2 and use coordinates/daysplayed only for the display in the middle

If you are familiar with coding, use this if a compass changes to something else, change it to the new compass id.

Known issue: If you use an addon with custom items, there is a possibility that the compass renderer will error (recommended to use subpack type 2), and if you use it on a server that does not activate days played or show coordinates, the resourcepack will not work.
