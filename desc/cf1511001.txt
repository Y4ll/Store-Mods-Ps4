Utility HUD (PC & Mobile)

It's an inventory overlay pack that adds some QoL features (PvP focused) in HUD. This type of packs were previously only possible on touch devices. But now it's possible thanks to T1M0THY's Discovery

It now works on both PC and Mobile!

Features

- Armor Durability

- Offhand Slot

- Mainhand Item Durability & in Inventory

- Potion Effects Overlay

- Fast Offhand Swap

- Fast Totem

- Item Counter (Free Slots, Golden Apple, Ender Pearls, Totems)

- Attack Crosshair

Usage (PC)

There's some of key combinations to use the features mentioned above.

- After joining the world press E to open inventory and all teh features will be active. Note: If you have potion effects active, press Z first to display Potion Effects Overlay and then press E. Make sure your Inventory is closed before you do this (To avoid unncessary Issues)

- To show/hide Inventory press Tab key

- To close Inventory press Esc key when it's visible. Note: You'll need to close the inventory before you open containers such as Chests, Villager Trades etc.

- F1+Hotkeys (1 - 9) to swap item in offhand. This will swap compatible items from that with the Offhand Item

- 1+F1 to fast equip totem from Inventory or Hotbar

- F8+Hotkeys (1 - 5) to show/hide features from this pack. You'll be shown a menu displaying which key to press for which feature.

- As F1 and F8 are normally used for Hiding HUD and Toggling Paperdoll, in order to do those now you have to press 2+F1 and 2+F8 respectively.

- Extra: If somehow your cursor goes out of focus then you can fix it by simply pressing Esc. To forcefully close potion overlay or Inventory screen press 3+F1

Usage (Mobile)

- You have to use Classic UI for this to work. Pocket UI isn't supported.

- First open inventory and you'll see a button appear on top of the inventory button. Clicking on it will show the inventory. And to hide it, click on the close button beside help button. Note: If you have effects then open the effects screen first.

- To close Inventory click on the close button on top right of the screen. Note: You'll need to close the inventory before you open containers such as Chests, Villager Trades etc.

- To swap items between hotbar and offhand, first click on the swap button and then click on the item you want to swap.

- To equip totems fast. Use the totem button. You can drag it around to your desired position. Note that it will reset it's position everytime you reload the world. To prevent that modify the config options.

- In order to temporarily solve a bug with crafting output, a new button was added that let's you craft items. But it will use all resources currently in the crafting grid. That's why there are two modes. One let's you put only one item at a time in the crafting grid and the other let's you put items normally. Note: This bug only happens in inventory screen. Crafting table works properly.

Config

You can find some options that you can modify about this pack in _global_variables.json file inside ui folder. There are explanation about the things you can modify.

Note: Golden Apple and Enchanted Golden Apple counts are combined.
