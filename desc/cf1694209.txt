What it is: a Spanish translation-only pack. It does not add Pokemon, new items, or gameplay systems; it works on top of CobbleDrock.

CobbleDrock y su contenido original pertenecen a sus respectivos autores. Esta traduccion no reemplaza a CobbleDrock ni reclama la autoria sobre el; solo proporciona texto en espanol y cadenas de interfaz cuando es posible.

1. Pack identity

- Name: CobbleDrock Traduccion Hispana (Spanish Translation)

- Version: 1.3.2

- Icon: WB CobbledRock logo with regional flags

- Description makes clear: translation only

- Stable UUIDs so updates in this 1.3.x line should not stack as separate packs

2. Items

- Spanish names (stones, gems, berries, medicines, balls, etc.)

- Tooltips / usage descriptions when the game reads them from .lang

- Fossils: tooltip shows which Pokemon can be restored

- Some duplicate description lines cleaned when the issue was in the language files

3. Party / summary screen

Translates labels such as:

- Dex No., Species, Type, OT, Nature (shown as Estado), Ability

- XP, Next level, Party, Held item

- Stats: HP, Attack, Defense, Sp. Atk, Sp. Def, Speed, Friendship

Does not translate (sent by Core in English): values like Water, Rash, Torrent, None, long ability descriptions, etc.

4. Starter selection

- Choose starter style UI text

- I choose you! button (more readable size)

- Region / selection UI text from the translation pack

5. Healing machine

- Spanish messages when Core uses translation keys, e.g.:

- party already fully healed

- party is being healed

- healed / in use / no Pokemon / not enough charge

-

6. Technical

- .lang files (es_ES, es_MX, es_AR, etc.)

- Translation-pack UI JSON (labels, sizes)

- Light BP support (tooltips) without replacing Core

- Does not import or override Core scripts; does not rewrite battle text via API

7. What this pack does not do

- Does not modify CobbleDrock Core

- Does not fix Ability None

- Does not translate capture lines like [Capture Success]... or returned to its Poke Ball

- Does not translate gym leader names

- Is not a content or multiplayer gameplay addon

One-line summary

Translates items, many UI labels, and language-keyed messages into Spanish; it does not change Core or all hardcoded battle/summary text.
