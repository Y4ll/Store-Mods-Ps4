This simple Add-On syncs your real life time into your Minecraft world.

Customization Options

The Add-On has built-in customization features:

- Enable RealTime: toggles whether to use the Add-Ons features or not. This option allows you to have complete control of the time of the world should you wish to do so, without having to completely remove the Add-On.

- Display time in actionbar: when enabled, your current real life time will be displayed for all players in the actionbar.

- Set timezone: allows you to select which timezone the time should sync on

- Time change easing time: determines the easing factor whenever the time changes. This can be drastically visible when the difference of the previous set time and the new time to set is great. Appropriately adjust this to suit your needs to avoid possible epileptic seizures.

Installation Notes

For the best gameplay experience, please take note of these before attempting to download the pack:

- This Add-On works in multiplayer.

- For Aternos, please refer to instructions here.

- You need to have an active Realms subscription to use this in Realms. To install on Realms, please check on Minecraft's website.

- Or locally via Wi-Fi or LAN.

- This Add-On modifies the player.json. And may NOT work with other Add-Ons or packs.

- This Add-On only supports Bedrock 1.20.70 or higher.
