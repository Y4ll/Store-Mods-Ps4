Hey guys my name is Daewron and I'm introducing this texture pack that makes touch buttons invisible.

I made all the touch buttons invisible, as well as the more recent ones like changing perspective and dismounting the ship or horse.

I was able to fix a bug with other "Invisible Touch Buttons" texture packs that would occur when drinking a potion. This caused another texture to display instead of the effect. Here's an example.

New:(29/06/25)

I decided to only add two options because my main idea was to make the texture but not so heavy because of a texture that only eliminates the touch buttons, So I decided to remove two options but you can still use it from version 1.1.0 to 1.1.5.

-Default: This option doesn't change anything.

-No invisible GUI: The name itself says it does not remove the menu buttons.

Available from 1.1.0 to 1.1.5:

-Transparent GUI: This option removes the background without removing the borders from the menu buttons.

Available only in 1.1.5:

-Transparent White GUI: Removes the background from the menu buttons and changes the button outline to white.
