HOW TO CHANGE THE SKIN TO YOUR OWN SKIN

- Locate the downloaded "funskin.mcpack" with Zarchiver (or any other file manager app in your phone)

- change the file name to "funskin.mcpack.zip"

- Extract the file then open the folder containing the pack assets

- You'll see "skin.png"

- Delete/Replace it with your own skin

- Change the file name to "skin.png" (don't rename with capitalize letters)

- Compress all the file into a zip again

- Rename it or Delete ".zip" so it'll go back to "funskin.mcpack" again
