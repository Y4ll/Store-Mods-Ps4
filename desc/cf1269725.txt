A new update has arrived, fixing existing bugs and adding new features to this package that seeks to revolutionize Minecraft Bedrock's graphics by using deferred lighting, making it as similar as possible to Minecraft Java. This is its four version, but I'll be developing it gradually. Keep in mind that this is the first deferred project I've created, and I'm fairly new to this, so some of the deferred projects already available might be better than this one.

Revolution Realistic

Revolution Default

This version has the same features as the realistic version only with vanilla skies

Revolution Vanilla

This version has the same features as the realistic version only with vanilla skies and water plane.

Featured

- The environment changes depending on the biome you are in; if it is cold it will be freezing and if it is hot it will be warm.

- Godrays depending on the color of the biome.

- Armor and reflective tools.

- Glow minerals.

This package has three different versions:

- Realistic Revolution: Realistic water waves, realistic clouds (cubemap), realistic caustics, and realistic sun and moon.

- Default Revolution: Realistic water waves, vanilla clouds, realistic caustics, and vanilla sun and moon.

- Vanilla Revolution: Vanilla Water Waveless, Vanilla Clouds, Vanilla Caustics, and Vanilla Sun and Moon.

Requirements

- Game Version: To try Vibrant Visuals, you need to enable the beta/preview version in Bedrock Edition and turn on the "Vibrant Visuals" option when creating or editing a new world.

- Vibrant Visuals in Minecraft Bedrock requires an Adreno 640 GPU (Snapdragon 855) or a Mali GPU (Mediatek 1000 series) for mobile devices. For PCs, a GPU with DirectX 12FL11 is recommended.

Mobile Devices

- Adreno 640 GPU: This GPU is found in the Snapdragon 855 processor.

- Mali GPU: The Mediatek 1000 series or a Mediatek GPU.

- A12 Bionic processor.

PC

- DirectX 12FL11: A GPU with DirectX 12FL11 is recommended for PCs.
