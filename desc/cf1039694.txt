Introduction

To start, we need to get the security table, this table can be created with just 2 materials.

We will need 3 iron ingots and 4 wooden sticks

With this security table, we can create all the available objects, such as: Security cameras, reinforced and password-protected chests, turrets, spy drones...

In order to use the camera, you need to follow these steps:

- Place the camera on a wall

- Interact with the camera to be able to add a reference name to it (It can be any name, but you can repeat a name that you have already used, ex: if you have a camera with the name: "my room", you can't rename a new camera with that name).

Done, the camera configuration has been successful, now we can use the camera from the tablet.

We will have 4 buttons available:

- Camera: This button lets you select one of your many cameras, when you select your camera, you will be able to see the camera perspective.

- Drone: This button lets you select one of your drones...

- Remove: This option lets you remove the camera that you want. (This option doesn't work for drones, if you want to remove a drone, you have to Shift and Right Click the drone).

- Remove All cameras: Well, you know what's that

While in a camera, we can continue using the tablet, we can return to ourselves, change cameras or use a drone.

Drones work the same way, but these are placed on the ground, and when they are placed on the ground, you interact with the drone to be able to assign it a name.

That's it, your drone is now set up and ready to fly. The drone has a signal limit, though, so if at any point you can no longer control it, you have to get closer to it so it can get a signal again.

Reinforced Chest

We have 2 types of reinforced chest.

- Normal reinforced chest: Only the one who placed the chest can open it

- Reinforced chest with password: Only the one who has the password can access it

You can identify the normal chests by the name, the normal chests do not have the word "KeyPad" in their name, another way to identify them is by the top of the chest model, it is completely white.

To identify the password protected safes, you can rely on the name, as the name includes the word "KeyPad", another way to identify them is by the top of the safe model, which has black dots.

There are 2 sizes of chest for each type, the small size and the large size of chest.

- Normal chest: Once you put these chests on the ground, you can open them. Nothing else is required; the owner of the chest is the one who put it there.

- Password Chest: When you place the chest, you will have to interact with it in order to set the password, once you set the password, you will have to memorize the password. Every time you want to use the chest, you will have to enter the password. Anyone can open it if they know the password.
