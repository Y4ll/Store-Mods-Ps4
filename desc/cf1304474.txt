Adaptive Cape v1.5

This texture uses each player's unique skin to generate a fully custom cape.

In v1.5 small changes were made, along with compatibility that did not exist before.

Compatible with Minecraft 1.21.120+

Basic Information

Capes

Adds a brand new animation system and 3 dynamic designs that automatically adapt based on official cape usage.

- Cape Movement Animation
The cape features smooth movement inspired by Java Edition capes.

- Normal Cape
Standard vanilla cape version, with standard elytra. Displayed if Adaptive Cape option is disabled

- Simple Cape
Displayed when the player is not using any official Minecraft cape.

- Better Cape
Requires an official Minecraft cape to be equipped.

- Custom Cape
Works like Better Cape, but allows a different skin-based configuration.

To use it correctly, make sure your skin follows this format (Slim or Wide):

Use this specific area of your skin to configure your Cape & Elytra:

- Green area Elytra, including the square used for custom symbols (6x6 or smaller if using a 64x64 skin).

- Turquoise area Center of the cape.
Red Left side.
Yellow Right side.
You can create patterns, logos, or fully custom designs.

- The showcase video demonstrates how to edit this section properly.

Elytra

Introduces the Adaptive Elytra, featuring the same behavior as the capes.
In v1.4, it received a brand new model designed to perfectly match the Custom Cape.

Settings

Starting from v1.4, Subpacks were removed and replaced by a new in-game configuration system.

- Adaptive Cape Enables or disables the adaptive function, keeping the improved cover animation appealing (Added in v1.5).

- Adaptive Elytra Enables or disables the adaptive elytra.

- Custom Cape Switches between adaptive and custom cape designs It depends on Adaptive Cape activated.

Notes & Compatibility

Capes

- Skins with heavy second-layer usage or 128x128 resolution may cause minor distortions.
The Better Cape mode handles these cases more efficiently.

- Skins created using the Minecraft in-game editor are not recommended, as they may break cape mapping.

Elytra

The Elytra system has been improved, but some animated textures may still present minor animation issues.

Resource Pack

Due to Bedrock limitations, it is not possible to view the adaptive capes through the game menu or skin editor, only in the loaded world or server (inventory, players, paperdoll, etc.)
