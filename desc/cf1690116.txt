flashlight shader

RD shader that adds flashlight and fish eye lens effect to your world.

note:

tinted particles are a bit bugged because of how the lighting detection works.

recommended settings:

fov: 80-100

brightness: 50%

this is RD shaders, so you need to use the correct tools to use this ( e.g. MaterialBinLoader, Minecraft patch, or any shaderloader ).

supported platforms:

Android, Windows, Ios
