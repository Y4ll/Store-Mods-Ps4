How to Use:

- Craft a Teleport Stone Use the given recipe to create a teleport stone.

- Set a Teleport Point Click the stone and enter a name to save the location.

- Teleport Use the stone again to instantly return to the saved location.

- Multiple Stones Craft and use multiple stones to set different teleport points.

Note: Teleport Stones are rare but can be collected!
