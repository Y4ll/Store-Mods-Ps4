Crate Delight

Expand your storage with crates and bags!
Crate Delight is a Vanillafriendly addon that lets you craft crates and bags to organize your resources, keeping your chests clutterfree and your inventory tidy.

This is a port of the Java edition.
Original Java version

Features

Storage Blocks: Compress 9 identical items into a single Crate or Bag.

Vanilla Friendly: Uses only Minecraft vanilla items and recipes.

Decorative Touch: Perfect for pantries, kitchens, farms, and storage rooms.

Fast Unpacking: Place a crate or bag in any crafting grid to instantly retrieve your items.

Crafting Recipes

To Pack (Craft a Crate/Bag):
Place 9 matching items in a 33 pattern in a Crafting Table.
Example: 9 Apples 1 Apple Crate

To Unpack (Retrieve Items):
Place 1 Crate or Bag anywhere in a crafting grid (even your 22 inventory).
Example: 1 Apple Crate 9 Apples

Changes from the Original Java Mod

This Bedrock Edition version is a full port of the original Java mod. All features were reimplemented from scratch using Bedrock components, items, blocks, and scripting.

Main differences from the Java version:

All crates and bags recreated using Bedrock item/block definitions.

Textures adapted to Bedrockcompatible formats.

Crafting recipes rebuilt using Bedrock JSON systems.

Java logic replaced with Bedrock scripting and vanilla component behavior.

Added Bedrockspecific optimizations for performance.

No Java code or assets are included; everything was recreated for Bedrock.
