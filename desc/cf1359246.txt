Proximity Voice Chat and Proximity Text Chat

Minecraft Bedrock will add the ability for players to talk to each other when they approach each other, similar to the simple voice chat mod in Minecraft Java.

Key Features

- Super Easy Setup: Simply configure your settings on our website and copy-paste the command!

- 3D Positional Audio: Hear other players from the direction they are standing.

- Mobile Support (iOS/Android): Join easily via your browser or our dedicated app.

- Server-Exclusive Addon: A special pack for servers that want to maintain a 24/7 persistent connection.

- Proximity Chat Support: Not just voicelimit text chat to nearby players as well.

How to use Proximity TC

Please enable Beta APIs. Use this if you want to apply distance limits to the standard text chat in addition to voice.

Main Commands

- /tc-help: Show help.

- /lang <ja/en/zh>: Change the display language.

- /distance <number>: Set the chat reach distance.

- /proximity <true/false>: Enable/Disable Proximity Text Chat.

- ...and more.

How to Connect on a Server

In your server.properties file, add the line: op-permission-level=4

Note: This will also allow server operations, like stopping the server, to be done via commands.

Behavior Pack (BP)

Please install only one of the following:

- Standard Edition (MCBE-ProxVC addon BP)

- Basic GUI settings and functional extensions.

- Server Edition (MCBE-ProxVC addon BP for server)

- Requires Beta APIs.

- Includes all standard features plus 24/7 constant connection. Keeps the VC system active even when the host is offline.

Resource Pack (RP)

- Displays icons above players' heads for "Talking," "Muted," "Speaking," etc., so you can see everyone's status at a glance!
