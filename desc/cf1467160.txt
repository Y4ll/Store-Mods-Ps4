After 6 long years, a much-loved shader has returned. It predates Minecraft's engine change, which rendered it unusable, but it's now functional again. Its purpose is to provide a somewhat realistic look for low-resource devices. Check it out, you've got nothing to lose.

- Reflection of the sun in the water and some surfaces (Day / Night)

- Fog like in the nether and end

Notes

- Need MBLoader.

- Need IPA File in iOS.

- You need BetterRenderDragon for Windows, in case it does not work, use the method of replacing material.bin files with Matject.

- I recommend that you the old version of this shader if you have it installed to avoid errors.

- This shader is only compatible with Android, Windows and iOS

- Use this mcpedl link if you want to share this shader.

- Please do not create another link for this shader.

- This shader may not be supported on some devices, if so tell me about the error on my Discord.
