How to Use

If you don't know the command list, you can type /xh or /xhelp to open this command list.

Open Menu:

- Type this command in chat to open the settings menu:

- /menu

- or

- /xm

- If you use "/xentium:" then it won't work because it requires cheats so you only need /menu and /xm to open it

Open Warps:

- You can open the warp list if there are already Warps filled in the Lodestone by typing

- /warp

- or

- /warps

- If you use "/xentium:" then it won't work because it requires cheats so you only need /warp and /warps to open it
