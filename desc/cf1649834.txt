HOW TO JOIN ON BEDROCK

- Open Minecraft Bedrock Edition

- Select Play

- Open the Servers tab

- Select Add Server

- Enter mcpe.pokefun.in as the server address

- Enter 19132 as the port

- Save the server

- Join POKEDROCK SMP POKEFUN
