INSTALLATION METHOD

Android

Using MB Loader App

1. Install MB Loader App

2. Launch Minecraft from MB Loader.

3. Import the resource pack and activate it in global resources.

Windows

Using Wyvern Loader

1. Download and setup Wyvern from here

2. Open Minecraft then click 'Inject' in Wyvern

3. Import the resource pack and activate it in global resources.

Linux / Mac

This method is for mcpelauncher-manifest.

Using MaterialBinLoader mod (Recommended): x86_64 arch

1. Install mcpelauncher-materialbinloader-mod.

2. Import the resource pack and activate it in global resources.

Using shaders mod: x86_64, x86, arm64, arm arch

-----------------------------------------------

1. Download mcpelauncher-shadersmod.

2. Follow this guide to setup.

iOS

Using shaders on iOS is not very straightforward and not recommended for beginners.

Using Minecraft with Hynis

1. Download Minecraft with Hynis IPA file from our Discord server.

2. Sideload it with your preferred sideloading tool.

3. Import the resource pack and activate it in global resources.

If you are having trouble following this guide, you can ask for support in Newb discord server.
