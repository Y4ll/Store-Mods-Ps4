Bosya's Selection Box

Selection Box is a simple resource pack that changes the default black selection box to a clean white outline, making it much easier to see which block you are aiming at in various environments.

Key Features

- White Outline: Replaces the default black outline with a clean white selection box.

- Two Subpack Variants:

- White Outline: Normal mode, follows depth (remains hidden behind blocks).

- Full: X-Ray mode, always visible through blocks.

- RenderDragon Compatible: Works seamlessly on the RenderDragon engine without requiring custom shaders.

How to Apply

- Download the .mcpack file.

- Open the file to import it into Minecraft.

- Go to Settings Global Resources and activate the pack.

- Tap the Gear Icon () on the pack to select your desired subpack variant.
