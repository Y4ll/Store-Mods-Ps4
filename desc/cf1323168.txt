This addon is inspired by Java Editions hidden food mechanics and rebuilt for Bedrock. Heres a quick look at what it does:

True Java Saturation

This addon brings Javas saturation mechanic to Bedrock, making health regeneration strategic.

[How It Works]

- Healing uses saturation Every time you regenerate health, saturation is consumed, just like in Java Edition.

- Better food = faster recovery Foods with higher saturation values let you heal more efficiently.

- True Java behavior Saturation only works if your hunger bar is full, mirroring Java Editions mechanics.

- Strategic gameplay Youll think twice before eating that cookie instead of a steak.
