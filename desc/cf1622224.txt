How to View Ingredients

- Obtain the "Recipe Book" item.

- Use the item to open the menu.

- Find the item whose recipe you want to view.

- Click on the item to view its ingredients.

How to Install

- Download the provided behavior pack file in (.mcaddon) format.

- Import file into minecraft bedrock.

- Before creating a world, dont forget to active the behavior pack.

- Create the world and done.
