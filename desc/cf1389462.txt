This add-on is an unofficial Bedrock Edition port of the Ultreon Devices Mod, originally created by MrCrayfish (MrCrayfish's Device Mod).

The modern Java port and updated assets were made by QubixMC, and this Bedrock adaptation brings a block-only decorative version of the mod to Minecraft Bedrock.

This version does not include functional features all devices are decorative blocks designed to enhance modern builds.

Included blocks:

- Office Chair (you can sit on it)

- Laptop (open/close)

- Router

- Printer

All blocks are purely decorative and safe to use in any world.
