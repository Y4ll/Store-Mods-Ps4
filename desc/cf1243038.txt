Overview

Build faster, smarter, and with precision.

Wans Construction Wands allow players to place blocks using advanced patterns and modes, making large-scale construction quick and efficient.
Features change depending on whether you play in Survival or Creative.

How it works:

- Select a mode

- Choose a pattern

- Pick your blocks

- Watch your structure take shape in seconds

The number of blocks and available patterns depends on the wand tier rarer materials mean more power.

Perfect for builders, redstoners, and anyone tired of repetitive block placing.

Usage

Quick Start

- Sneak + Use -> Open configuration menu

- Use Tutorial Book -> Learn all features in-game

- Click a block -> Select block type

- Use the wand -> Execute the selected pattern

- Sneak + Use -> Always opens Main Menu

- Hotbar shows preview count (->N) before confirming

Construction Mode Patterns

- Line Straight line in view direction

- Connected Fill connected blocks of the same type

- Circle (Iron+) Horizontal or vertical circles

- Wall (Iron+) Flat walls with adjustable size

- Sphere (Diamond+) Hollow or filled 3D spheres

- Cube (Diamond+) Hollow or filled 3D cubes

- All geometric patterns support Repeat and Mirror via Advanced Settings

- Block Randomizer build a palette of up to 4 block types; each block placed is chosen randomly

Destruction Mode Patterns

- Connected Remove connected blocks of the same type

- Area Destroy Remove blocks in a area

Replace Mode

- Click the block to find

- Click the block to replace with

- Click the find block again to execute the replacement

Undo System

- Undo your last 3 operations directly from the Main Menu.

- Works for construction, destruction, and replace. Large operations restore in batches to prevent lag.
