Notes

- This shader includes a "Lite" version for low-end devices; it replaces the clouds with lighter ones that still look good, removes sky reflections from the water, and eliminates plant movement.

- I recommend using this shader alongside Bare Bones. Place Bare Bones above the shader to avoid errors.

- Need Minecraft v26.40+ and MBLoader.

- Need Minecraft Hynis in iOS.

- You need Wyvern for Windows, in case it does not work, use the method of replacing material.bin files with Maject.

- I recommend that you the old version of this shader if you have it installed to avoid errors.

- This shader is only compatible with Android,Windows and iOS
