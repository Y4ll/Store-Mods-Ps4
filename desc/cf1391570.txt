NOTE

This pack includes multiple item configuration files.

If you want your custom items to display correctly, you must select the correct file for each item inside the subpacks options.

Each subpack contains a different setup, so item behavior is not automatic it must be chosen manually.

ALERT

Be careful when selecting your subpack!

Make sure you pick the version that matches the system you are using:

Action & Stuff subpack for Action & Stuff users

Prizma subpack for Prizma users

Choosing the wrong subpack may cause items to render incorrectly or not appear in 3D.
