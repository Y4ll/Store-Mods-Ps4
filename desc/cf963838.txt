Installation

Load the pack into the game after downloading it that's all!

If you prefer manual installation,

After downloading, rename the .mcpack file to .zip and unzip it.
Go to the following address:
AppData\Local\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\resource_packs
replace the unzipped Elys PBR file
Launch Minecraft go to settings select Elys PBR and activate it

Note: For spectacular visuals, use the Better RTX Graphics mod.
