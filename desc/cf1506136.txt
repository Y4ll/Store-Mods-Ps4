This addon is a Bedrock Edition recreation of "Siren Head: The Arrival", faithfully adapting the atmosphere and core gameplay from the original Java mod.

Original Java Mod by @Kihec - @YeOldeDingus - @Rupter: https://www.curseforge.com/minecraft/mc-mods/siren-head-the-arrival

----------------------

See the port in the video below everything is 100% accurate!

Try it yourself for the best experience; don't let its sounds fool you. Be careful the trees xD

He can spawn anytime, anywhere you least expect it

----------------------

This is NOT the original Java mod.

This is a full Bedrock Edition port rewritten using Minecraft Bedrock systems and Script API.

----------------------

Differences from the original Java version:

- Fully rewritten for Minecraft Bedrock Edition.

- AI behavior adapted to Bedrock limitations.

- Certain mechanics adjusted due to engine differences.

- Optimized for Bedrock multiplayer compatibility.

- Some features may slightly differ due to technical differences between Java and Bedrock Editions.
