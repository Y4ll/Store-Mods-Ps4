installation guide

On Android

- MB Loader and a copy or original of the game on your phone. this is needed to support RenderDragon shaders.

How to use MB Loader

- Search for MB Loader on the Play Store.

- Install MB Loader.

- Open MB loader.

- Grant the required permissions.

- Import the package using MB loader.

- Launch Minecraft from the MB loader.

- Enable the shader in the global resource packs (never in the world packs).

- Play.

On Windows

formerly it was used BetterRenderDragon and the matject tool on Windows, but due to constant changes in the file code, these methods stop working; now I present a new tool for loading shaders on Windows. Wyvern is a new shader loader made by mcbegamer in collaboration with loddingglue for windows, it works in a near non version dependent way that allows it to work on more minecraft versions without updates, keep in mind you need to add your shaders into global resource packs or else it wont work, it also contains a simple gui so you can inject the loader into minecraft windows.

How to use wyvern

- Install

- Open Minecraft

- Run Wyvern

- Apply GR shader (Global Resources)

- Play

On iOS

- Need IPA File in iOS.

- rename .mcpack file to .zip

- extract the contents of the renderer folder

- Make a copy of the 'renderer' folder from the Minecraft IPA.

- Place the shader's `renderer` folder into the Minecraft IPA.

- install the modified IPA

- export the texture and place it in the RG

- play

- If you want to revert the changes made before the shader step, place the renderer folder from the backup into the modified IPA.
