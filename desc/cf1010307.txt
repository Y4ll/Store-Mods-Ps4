Vanilla DX: LCE/4JD UI:

Before "Modified Vanilla: Console UI Pack".

Codename: Project 4JD UI

Is an "unofficial" testing/experimental resource pack that would change some UI designs, and the goal of this project is convert from default UI to high accuracy possible LCE/4JD UI RP for Bedrock Edition users, replacing some designs to look more similar!

For the time being, only an adaptive version will be available due to the modified UI limitations.

Features:

- Legacy Console Edition UI designs with 70% accurate.

- Main screens, menus and inventories have been modified, not all, but I will add more screens in future versions!

- Some UI customizations by "ui/_global_variables.json".

Upcoming features for future versions:

- Help sections.

- Credits screen.

- New font type.

- New storage management.

- Play Screen and Create World Screen.

Unsupported Screens due to Ore UI replacement (Hardcoded):

- Play Screen

- Settings/Options Screen

- Create World Screen with templates

- Disconnected

- Achievements

- In bed/Sleeping

- You died!

- Permission List Screen

Supported Languages:

- English (en_US and en_UK).

More full languages support is coming in near future updates.

Known Issues:

- In Trade v2 screen, at the moment it is not supported for use on third-party servers, and when using gamepad, the accuracy is not 100%.

- At the moment, it is not recommended for use with another resource pack, much less when applied to a single world.

- And unfortunately, since the Ore UI (new UI engine) appears for some screens, it is impossible to modify it using resource packs. However, I have plans to make modifications using something external, for now I must make research about CSS, JS and HTML, I will let you know if something happens...

- Obviously, you can't use it with other resource packs that have modified UI. You will have to wait for me to make it compatible in a possible way.

And how do I deactivate this resource pack?

If this is your first time experimenting with the UI, just go to "Help & Options" -> "Settings" -> "Graphics" and click the button where it says: "Resource Packs".

And then this screen comes out and you can deactivate this. That's all! ;D
