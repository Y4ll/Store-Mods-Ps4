This addon features 3D Block Characters such as Uppercase Letters(A-Z), Lowercase Letters(a-z), Numbers(0-9) and some Symbols(?#@...). Use this to decorate your personal build project or add some fun to some of your builds.

The characters is styled like a "regular random font", since many addons already features "Minecrafty" font style. This also features lowercase letters and a more convenient way to put color to each characters.

Note:

- Minimum Minecraft version requires v1.21.60 above

- Not created for survival mode use, maybe in future updates

- For the meantime, this addon can be used conveniently to any of your creative mode
builds!

How to use:

It's easy!

You can interact / click the 3D character block with the following items:

- Dyes= to change color (Default: White)

- Glow ink sac = to put lighting / luminance (Default: No light)

- Ink sac = to remove lighting / luminance

- You can also place each characters to item frames
