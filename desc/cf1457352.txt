V1.3.1 ChangeLog :

-Now compatible with every single gun addon that you want to use !

-Optimisation for better performances and less lag

-All of the 3d models have been remade for better accuracy to Warthunder

-Added the Fw190-A1

-New shell system you can shoot aphe, he, ap, apcr, aphebc and heat not every tanks can fire every shells so make sure to use the right shell ! (get the shells by crafting them or just get them in the creative mode if you're too lazy)

-Bombs now do radius damages meaning that you don't have to land it directly on the target, if it lands next to it, it will still destroy it

-New weak spot system for tanks with effective armor thickness calculation vs shell penetration capacity. This is way more advanced and realistic than the other system. The new system allows accurate kills (crew knocked out, ammunition exploded) and logic ricochets

-U can switch between camos using a snow block, a sand block to adapt to the battlefield ! You can get back to the original camo by using a dirt block.

-Add bushes by interacting with oak leaves (use shears to remove them)

-Add additionnal armor on the shermans by using the tank track item (yes it actually Increases the protection isn't it crazy ????)

-Fixed a lot of bugs, like mgs being able to kill tanks, vehicles starting to act weirdly if there was too many of them etc

-New loading screen
