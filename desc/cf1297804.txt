Installation Guide

Android

- Download MT Manager or APK Editor 3.0

- Copy "cameras" and "__brarchive" folders from downloaded file

- Using MT Manager or APK Editor paste them inside APK path:
"/assets/assets/resource_packs/vanilla/"

- Click "Replace" and build and install that APK.

IOS

- You need Jailbreak for this.

Windows

- Downlaod IOBit or Windows Explorer

IOBit Tutorial (Youtube)

Windows Explorer:

- Copy "cameras" and "__brarchive" folders from downloaded file

- Paste it in
"C:\XboxGames\Minecraft for Windows\Content\data\resource_packs\vanilla\"

- Then click on "Replace all"
