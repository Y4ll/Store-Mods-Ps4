This addon allows you to see you're self in a first person perspective cam made by OGcrafter, it was inspired by the java mod "first person model" and I was able to recreate it in bedrock edition so the mobile players could finally get to have a bit of immersion

To enable the mod you need to download it from the link in mcpedl and run it in Minecraft then enable them in you're world or in a new world and make sure to enable the "experimental creator camera features" found in the experimental tab while editing/creating the world

Also if you want the best experience then you should have these video settings :

1. fov ranging from 60 to 70

2. Turn off "fov can be altered by gameplay

Please note : do not download this pack from untrusted links ,only download it from mcpedl or curseforge , and don't expect an update everyday and if Minecraft does something that breaks the mod pls don't be mad instead I will be because I spent months trying to figure this camera features thing ,let's just hope they make things better instead of ruining it

Stuff to keep in mind :

This addon is probably compatible with 75% of mods and will 100% work if the other mod ur using has custom items/armor/food/weapon/projectile and texture packs that don't change player animations

However if you want to run it with player animations packs it will work but it will have bugs and stuff will feel off but not completely so feel free to strap in a player animation pack to increase immersion just make sure that my pack is on top of it in the resource pack tab for 75% guarantee of working
