See what you are looking at directly from your HUD! This utility Add-On adds a display on top of your screen, packed with intuitive and useful information about the world around you.

Features

- Intuitive display design

- Multiplayer & survival-friendly

- Displays the block/entity name, and the Add-On it is from

- Renders the block/entity icon accurately

- Shows which correct tool to use, and if you're holding it or not

- Works with most other Add-Ons and packs

- Supports all languages

- Lightweight, and easy to use

Screenshots and Previews

Customization

You can run the /waila command to customize tailored to your needs! Alternatively, you can also adjust the WAILA setting for other players by running it like so: /waila [player (requires you to be opped).

Installation Notes

For the best gameplay experience, please take note of these before attempting to download the pack:

- This Add-On works in multiplayer.

- For Aternos, please refer to instructions here.

- You need to have an active Realms subscription to use this in Realms. To install on Realms, please check on Minecraft's website.

- Or locally via Wi-Fi or LAN.

- This Add-On does not modify the player.json. So it should work with other Add-Ons.

- This Add-On only supports Bedrock 1.21.100 or higher.

- This Add-On does NOT require any experimental toggle.
