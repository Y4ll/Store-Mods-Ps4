X-ray Bedrock all Versions Minecraft PE Resource Pack

Description

A lightweight X-ray resource pack for Minecraft PE (Bedrock Edition) version 1.19.60+. This pack hides all blocks except for ores and gravel, making it perfect for efficient mining and resource hunting.

Built using the default 16x resolution. No gameplay changes just visual improvements for mining. Compatible with mobile and Windows 10/11 Bedrock Edition.

note: this pack works best with a Night Vision Potion or FullBright Pro Resource Pack by Leo Termado

Features

- Only ores and gravel are visible

- Everything else is transparent

- Works on Minecraft Bedrock 1.19.60 - 26.0

- Older versions available too!

- Default 16x resolution

- Lightweight and easy to use
