X-Ray Outline is a Minecraft Bedrock texture pack designed to make ores easier to find through blocks with a clean and visible outline.

Instead of making everything completely transparent, X-Ray Outline keeps the X-Ray effect clean while giving ores a distinct border that makes them easier to spot.

Features

- X-Ray vision

- Visible outlines around ores

- Easier ore detection

- Clean and simple X-Ray appearance

- Achievement friendly

- Designed for Minecraft Bedrock

Instructions

For the best experience, use these settings:

- Disable Smooth Lighting in Minecraft.

- Set Minecraft Brightness to 100%.

- Set your device display brightness to 100%.

- For better visibility, use Night Vision Plus.
