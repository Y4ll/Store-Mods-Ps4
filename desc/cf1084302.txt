New variants for the Candle Golem!!

16 new variations for the Candle Golem.
To make it, simply change the color of the candle you use when summoning it. VERY EASY TO MAKE!

Candle Golem
This golem is a companion for the player, it lights up the caves for you and can be a mobile light source. Great for exploring caves without having to use the dynamic light addon.

Health: 100
Attack: 0 (He does not defend the player)

Speed: Super Fast

Skill: Dynamic Light

It is repaired with: Honeycomb and Honeycomb Block (recovers 50 and 100 health)

How to Make?

If you want to make it a specific color, replace the conventional candle with a colored one. If the candle is red, the candle golem will be red; if it is blue, it will be blue.
