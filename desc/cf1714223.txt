Installation (Required)

This UI Pack requires YashGameplay's Main UI to work properly.

Download YashGameplay's Main UI:
https://www.curseforge.com/minecraft-bedrock/texture-packs/yashgameplays-main-ui

Setup Guide

Download and import YashGameplay's Main UI.

Download and import this Black Bird UI Pack.

Open Settings Global Resources.

Place this Anime UI Pack above YashGameplay's Main UI in the Global Resources list.

Activate both packs and enjoy your new interface.

Related

This UI Pack is an add-on for YashGameplay's Main UI, so make sure both packs are enabled.
