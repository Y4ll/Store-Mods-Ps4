How to Install

This file is an mcpack, but you must rename it to a zip file, extract it, and then proceed with the work.
Installation on iOS
Open the file app, move to "On My iPhone => Minecraft => internal => premium_cache => skin_packs" and delete all files. Then rename the mcpack to zip, move the extracted files into "skin_packs" This completes the installation.
Installation on Windows 10 / 11
Press win+R and paste "%appdata%\Minecraft Bedrock\premium_cache\skin_packs" and run. Delete all files inside "skin_packs" Then rename the mcpack to zip, move the extracted files into "skin_packs" This completes the installation.
