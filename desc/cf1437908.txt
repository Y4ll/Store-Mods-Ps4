How to Use

Main Control Panel

Activate both packs, complete onboarding, then use the supplied VeinGlow book to open the main dashboard and configure mining.

Quick In-Hand Menu

Rename a tool to VenFlow or Quick. Sneak or use the configured interaction method while holding it.

Basic flow: select a pattern, choose activation and filters, hold the correct Vanilla tool, preview the target blocks, then activate mining.

Critical Safety Rules

- Sneak activation: prevents unintended large mining operations when enabled.

- Immediate cancellation: releasing the configured activation stops the current session.

- Vanilla checks: tool tier, durability, hunger or XP cost, block filters, and maximum limits remain enforced.

- Tool protection: mining can stop before a tool breaks.

Configuration & Administration

- Configure maximum blocks, mining delay, durability threshold, hunger or XP cost, and item magnet behavior.

- Enable or disable patterns, passive abilities, preview systems, and individual particles.

- Set block filters for each supported tool category.

- Settings are stored per world and per player where appropriate.

- Activate the Behavior Pack and Resource Pack on the same world.
