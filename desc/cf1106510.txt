Description

This pack brings back the Classic Minecraft panorama but with shader applied making it look more beautiful. The time of day is adjusted to resemble the original panorama, with subtle improvements to the sunrise appearance. Currently, it uses the new textures, but I'll add old textures too as an option soon. I'll also add some other variations, like night mode!

Versions

There are three versions of this pack, each with different image sizes:

- 1024x1024 pixels: This, or the 1440x resolution (if it's working for you) version is recommended.

- 1440x1440 pixels: For higher quality, though it may be slower to load on some devices due to its larger size.

- 720x720 pixels: Only needed if you have very low storage, if the higher resolution versions aren't working for you, or you just want it to be lighter.

If youre on Curseforge, go to the Files tab to download the version you want.

Note

This is not a shader and does not include one; this is a resource pack to just change the panorama/background to those shown in the screenshots.

It should work on almost any version of Minecraft; you can ignore warnings. If your Minecraft version is too old, you might have to edit the manifest.json file of this pack.
