McStore

Publica tus packs para todos los que tienen la app: se suben al repositorio y, en 1-2 minutos, aparecen solos en el catalogo.

Configuracion (solo la primera vez)

1. En GitHub: Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
2. Repository access: Only select repositories → Store-Mods-Ps4. Permissions → Contents: Read and write.
3. Copia el token y pegalo aqui. Se guarda solo en este telefono.

Limite: unos 50 MB por archivo. Si un archivo ya existe con el mismo nombre, se reemplaza.
