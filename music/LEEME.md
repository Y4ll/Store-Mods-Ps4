# Musica propia para McStore

1. En GitHub (Safari): Add file > Upload files, y sube aqui un .mp3, .m4a, .ogg o .wav.
2. La accion "Convertir musica" lo convierte sola a `music/musica.wav` (mono, hasta 5 minutos) y borra el original.
3. En la PS4: Ajustes (Triangulo) > Preferencias (Cuadrado) > "Musica propia" > X.

Cuadrado en esa fila quita la musica propia. Ojo: este repositorio es publico, asi que lo que subas aqui lo puede bajar cualquiera.
